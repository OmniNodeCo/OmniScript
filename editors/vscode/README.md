# OmniScript Language for VS Code

Language support for `.omni` files:

- OmniScript syntax highlighting
- nesting-aware comments and bracket rules
- declaration/control-flow snippets
- **Run Current File** and **Check Current File** commands

Install the `omni` CLI first. To develop the extension, open this directory in VS Code and press F5. There are no npm dependencies and no compile step.

Set `omniscript.executable` if the CLI is not available under the default `omni` command name.
